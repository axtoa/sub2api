# Sub2API v0.2.17

本版完善上游质量监控、余额管理与 CDK 商品管理。

- 质量监控增加上游质量评估：展示六项维度得分、证据覆盖率、样本量、分组排名，以及可容忍问题、待复核问题和底线问题。保留原有账号优先级排序。
- 渠道检验增加输入用量对照与重复能力检验，支持选填官方、可信渠道、历史报告和手工计数参照。无参照时保留有限条件下的检查；用量差异不会直接认定为注入或模型造假。
- 自定义问题可保存到题库、编辑并在检验时选择。外部资源库支持分类、描述、跳转和管理，收录测评、排名及中转业务相关资源。
- 上游余额支持 New API 查询与选填的账户访问令牌配置；钱包展示累计消费，并可直接打开关联账号的 API 地址。
- CDK 商品保存后支持编辑；管理员可查看库存兑换码。

## 升级说明

- 升级前备份主站、商城数据库及现有部署配置，继续使用原有数据库和密钥。
- 本版新增迁移 251–258，由服务启动时自动执行。258 新建质量评估配置与证据表；不需要删除旧数据或重建钱包。
- New API 账户访问令牌为选填，需使用固定的服务端加密密钥；已经配置的密钥须保持不变。Sub2API 余额查询无需填写该令牌。
- 新增审计项目默认不勾选。手动或批量检测前核对页面展示的请求量；保存配置与查看评分不会发起付费模型请求。
- 质量评分依赖实际样本与可比条件。证据不足时不参与排名；模型交付、计费及隐私问题保留人工核验记录。
- 回滚保留新增表和已经产生的数据，不倒退迁移。

## 验证

相关前端测试 68 项、前端生产构建、质量与余额后端检查、临时 PostgreSQL 集成及并发检查通过。验证使用模拟上游，未发起真实付费检测。远程 CI 和镜像发布结果以对应 GitHub Actions 记录为准。
